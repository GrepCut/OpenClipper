Smart Crop — Automatyczne Kadrowanie Wideo

Smart Crop (UI: Smart Follow) to inteligentny system automatycznego reframingu wideo pod docelowe formaty (TikTok 9:16, Instagram 1:1, YouTube 16:9…). Zamiast statycznego centrowania, system analizuje zawartość klatki, buduje dynamiczną ścieżkę kamery i wybiera optymalny layout w czasie rzeczywistym.

Detekcja → AutoFlip Track → Layout Planning → Render / Podgląd

Trim & Detekcja
WinML pipeline (Rust/ONNX) dekoduje klatki i uruchamia inferencję: BlazeFace, YOLOX, pozy, ByteTrack, detekcja letterboxa.

🎥 Etap 2 — buildAutoFlipTrack() — serce przetwarzania

Funkcja buildAutoFlipTrack(input) zamienia surowe detekcje w kompletny ClipperSmartCropBlob. Plik: engine/autoflip/build-autoflip-track.ts

Krok 1
Normalizacja przestrzeni → contentRect
validContentRect() waliduje i clampuje contentRect. detectionsInContent() mapuje wszystkie detekcje (boxy, keypoints, pozy) z przestrzeni źródłowej do przestrzeni aktywnego contentu (0–1), usuwając czarne pasy.
intoContentRect(box, content) → normalized coords bez letterboxa
Krok 2
Tożsamość → Canonical Person Tracks
canonical-person.ts łączy detekcje person + face + pose w spójne canonicalId. active-speaker.ts dodaje sygnał mówcy (LR-ASD) — kto aktualnie mówi.
buildCanonicalPersonTracks() → applyActiveSpeakerPolicy()
canonicalId activeSpeaker
Krok 3
Salient Keyframes (co ~200ms)
salient-region.ts buduje regiony istotne co ~200ms z twarzy, poz, detekcji YOLOX. Każdy region ma sygnał: face_core, face_all, human, pet, car itd. z odpowiednimi wagami.
buildSalientKeyframes({ clipStart, clipEnd, detections, sceneCuts })
Krok 4
Importance Ranking
importance-ranker.ts klastruje regiony, nadaje role (primary / secondary / candidate) i wynik ważności (importanceScore). Każdy region ma box (centrum), contentBox (szerszy kontekst) i kind (face, head, speaker, person, action…).
attachImportanceSignals() → buildImportanceTimeline() → ImportanceRegionSample[]
Krok 5
Podział na sceny
splitScenes() dzieli klip na sceny wg sceneCuts. Długie sceny są chunked do max AUTOFLIP_MAX_SCENE_FRAMES / fps sekund. Kontynuowane fragmenty mają continueLastScene: true.
splitScenes(clipStart, clipEnd, sceneCuts, fps) → Scene[]
Krok 6 — Per format, per scena
Jednolite tło + brak foreground?
staticFeatures hasSolid && !hasForegroundSalience(keyframes)
✓ TAK — Padding path
Zachowaj cały contentRect
Slajd / gameplay — zamiast wycinać, renderer użyje solidBackgroundColor jako padding. Crop = pełny contentRect.
motionType: "padding"
✗ NIE — Ścieżka kamery
analyzeSceneMotion → cropScenePath
1. analyzeSceneMotion() — typ ruchu sceny: tracking / static
2. cropScenePath() — kinematyka One Euro / wielomian
3. expandCropAcrossBars() — rozszerzenie cropa na pasy letterboxa
motionType: "tracking" | "static"
Wynik kroku 6
aspectTracks[formatId]
Jeden niezależny tor kamery na każdy format crop. samples: AutoFlipCropSample[] = {t, crop: NormalizedBox, cut?, solidBackgroundColor?}
aspectTracks["tiktok"] = { targetAspectRatio: 0.5625, samples: [...] }
Krok 6.5
Shot Crop Smoothing
shot-crop-smoothing.ts — wygładzanie crop na granicach ujęć (feature flag: shotCropSmoothingEnabled()).
→ Dalej
Do Layout Planning (Krok 7)
aspectTracks + importanceSamples → buildLayoutTracks() → arbiter → layoutTracks
🏗️ Etap 3 — Layout Planning & Arbitration

Warstwa decyzyjna: planner generuje propozycje kadrowania, arbiter wybiera najlepszą, visibility controller ratuje utracone obiekty.

Propozycja A
Baseline (Run 4 — AutoFlip)
Bezpośrednio z aspectTracks — klasyczna ścieżka kamery zbudowana z regionów salient. Stabilna, sprawdzona w produkcji.
strategy: "legacy-baseline"
viewports = [crop z aspectTrack]
Propozycja B
Semantic (Importance-based)
Z importanceSamples — uwzględnia role semantyczne (primary/secondary), oferuje tryby: single-crop, split-screen, contain.
strategy: "semantic-single" | "semantic-split" | "semantic-contain"
viewports = [semantic framing]
Decyzja
layout-arbiter.ts — Arbiter
Porównuje propozycje wg progów stabilności, pokrycia regionów wymaganych (requiredCoverage), i jakości framingu. Zwycięzca przechodzi do layoutTracks.
RUN10_ARBITER_PARAMS → baselineScore vs semanticScore → winner
decisionConfidence reasonCodes
Zabezpieczenie
visibility-controller.ts
Ratuje przypadki utraty widoczności wymaganych regionów. Drabinka counterfactual: shifted-crop → wider-crop → stable-split → contain-fail-safe.
candidateVariants: ["shifted-crop", "wider-crop", "stable-split-v2", "contain-fail-safe"]
visibilityRisk: boolean
Wynik końcowy
ClipperSmartCropBlob
Kompletny blob zawierający: aspectTracks, importanceSamples, layoutTracks, telemetrię, metadane wersji. Zapisywany do smart_crop_analysis.json.
session.smartCropAnalysis = blob;
writeClipperSmartCropAnalysis(projectId, blob);

3 tryby layout

ModeOpisKiedy
single-crop Jeden kadr — klasyczne reframing Jedna osoba / obiekt, scena statyczna lub tracking
split Split-screen — dwa viewporty (podcast) Dwie osoby oddzielne przestrzennie, rozmowa
contain Cały obraz + padding Slajd / gameplay / treść, której nie można wyciąć
🖼️ Etap 4 — Render klatki

Funkcja drawClipperFrame() w frame-draw.ts — wspólna dla podglądu na żywo i eksportu finalnego. Gdy cropMode === "smart-follow" i format ma mode === "crop":

Wejście render
drawClipperFrame(formatDef, ctx, frame, source, output, t, render)
Kontekst renderu: ClipperFrameContext zawiera settings, captions, faceCache, faceRender, smartCropAnalysis, segments.
cropMode === "smart-follow" && format.mode === "crop"?
✓ Smart Follow
resolveClipperLayoutRender(blob, formatId, source, t)
Próbuje pobrać layout decyzję (v3) z layoutTracks. Jeśli istnieje — idzie do dedykowanego renderera.
✗ Inny tryb
face-follow / center / manual
Śledzenie twarzy z faceCache, centrowanie lub ręczne kadrowanie — bez Smart Crop.

Priorytet renderu w Smart Follow

1
layoutTracks (split)
drawClipperLayoutFrame() → dwa viewporty, podcast layout. Możliwe do wyłączenia per-region przez użytkownika (disabledCollageRegionIds).
2
Collage (face pipeline)
drawPodcastCollageFrame() → split oparty na twarzach, gdy użytkownik nie wyłączył regionu i format jest eligible.
3
aspectTracks (AutoFlip crop)
resolveAutoFlipCropRender() → drawClipperPlatformFrame(). Interpolacja liniowa crop między próbkami; przy cut: true — skok bez pana.

Interpolacja czasu

interpolateAutoFlipCrop(track, time)
Binary search po próbkach → liniowa interpolacja na x, y, width, height. Przy cut: true — trzyma poprzedni kadr (brak sztucznego pana między ujęciami).

Padding: Gdy proporcje crop ≠ proporcje wyjścia → renderer używa rozmytego tła lub solidBackgroundColor ze sceny (slajdy).

Warstwa 1 — AutoFlipAspectTrack

Jeden niezależny tor kamery na każdy format. crop to pełny prostokąt w przestrzeni źródła w znormalizowanych współrzędnych (0–1). To jest ścieżka Run 4 / AutoFlip baseline.
{ targetAspectRatio: 0.5625, samples: [{ t: 0.0, crop: { x: 0.3, y: 0, width: 0.4, height: 1 }, cut: false }] }

Warstwa 2 — ImportanceRegionSample

Regiony ważności semantycznej: twarz, głowa, mówca, osoba, akcja, ekran, obiekt. Każdy region ma box (centrum celu), contentBox (szerszy kontekst), importanceScore, role (primary / secondary / candidate).
{ time: 1.2, regions: [{ id: "r0", box: {...}, contentBox: {...}, kind: "speaker", importanceScore: 0.95, role: "primary" }] }

Warstwa 3 — ClipperLayoutTrack

To jest to, co faktycznie wybiera renderer w trybie Smart Follow (gdy layout jest dostępny). Każdy sample ma mode (single-crop / split / contain), viewports (prostokąty źródłowe), strategy (legacy-baseline / semantic-single / semantic-split / detector-splice).
{ t: 1.2, mode: "split", strategy: "semantic-split", viewports: [{...}, {...}], requiredRegionIds: ["r0", "r1"] }

Ratowanie widoczności wymaganych regionów. Drabinka: shift → wider → split → contain.

Fuzja person + face + pose w canonicalId. Kalman + IOU + appearance matching.

Polityka active speaker (LR-ASD). Kto aktualnie mówi → wpływa na framing priority.

Wygładzanie crop na granicach ujęć — zapobiega artefaktom na sceneCuts.
kinematic-options.ts
Parametry kinematyki per smoothing level (smooth / balanced / snappy).
generalization-flags.ts
Feature flagi: smoothing, group union, shot crop smoothing, hypothesis bank authority.
